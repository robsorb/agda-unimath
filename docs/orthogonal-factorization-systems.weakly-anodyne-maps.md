## Idea

A map $j : C → D$ is said to be
{{#concept "weakly anodyne" Disambiguation="map of types" Agda=is-weakly-anodyne-map}}
with respect to a map $f : A → B$, or **weakly $f$-anodyne**, if every map that
is local at $f$ is also local at $j$.
