## Idea

Given two elements `x` and `y` in a poset `X`, the **interval subposet**
`[x, y]` is the subposet of `X` consisting of all elements `z` in `X` such that
`x ≤ z` and `z ≤ y`. Note that interval subposets need not be linearly ordered.
