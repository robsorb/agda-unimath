## Idea

An {{#concept "equivalence of arrows"}} from a function `f : A → B` to a
function `g : X → Y` is a [morphism of arrows](foundation.morphisms-arrows.md)

```text
         i
    A ------> X
    |    ≃    |
  f |         | g
    ∨    ≃    ∨
    B ------> Y
         j
```

in which `i` and `j` are [equivalences](foundation-core.equivalences.md).
