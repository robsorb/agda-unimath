## Idea

Given a ([dependent](foundation.dependent-inverse-sequential-diagrams.md))
[inverse sequential diagram](foundation.inverse-sequential-diagrams.md) `A`, we
can extract the **composite map from `Aₙ₊ᵣ` to `Aₙ`**.
