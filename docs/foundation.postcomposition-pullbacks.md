## Idea

Given a [pullback](foundation-core.pullbacks.md) square

```text
         f'
    C -------> B
    | ⌟        |
  g'|          | g
    ∨          ∨
    A -------> X
         f
```

then the exponentiated square given by
[postcomposition](foundation-core.postcomposition-functions.md)

```text
                f' ∘ -
      (T → C) ---------> (T → B)
         |                  |
  g' ∘ - |                  | g ∘ -
         |                  |
         ∨                  ∨
      (T → A) ---------> (T → X)
                f ∘ -
```

is a pullback square for any type `T`.
