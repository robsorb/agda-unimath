## Idea

A [semiring](ring-theory.semirings.md) `A` is said to be
{{#concept "commutative" Disambiguation="semiring" Agda=is-commutative-Semiring}}
if its multiplicative operation is commutative, i.e., if `xy = yx` for all
`x, y ∈ A`.
