## Idea

Given a family of maps `g : (x : X) → C x → C (f x)` over a map `f : X → X`,
then `g` can be
{{#concept "iterated" Disambiguation="family of maps over a map of types" Agda=iterate-family-of-maps}}
by repeatedly applying `g`.
