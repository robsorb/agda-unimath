## Idea

A **morphism** of coalgebras of a polynomial endofunctor `P A B` consists of a
function `f : X → Y` between their underlying types, equipped with a homotopy
witnessing that the square

```text
              f
      X -------------> Y
      |                |
      |                |
      ∨                ∨
  P A B X ---------> P A B Y
           P A B f
```

commutes.
