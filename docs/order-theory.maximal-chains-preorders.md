## Idea

A
{{#concept "maximal chain" Disambiguation="in a preorder" Agda=maximal-chain-Preorder}}
in a [preorder](order-theory.preorders.md) `P` is a
[chain](order-theory.chains-preorders.md) `C` in `P` such that for any chain `D`
we have `C ⊆ D ⇒ C ＝ D`.
