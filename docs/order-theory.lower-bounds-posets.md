## Idea

A **lower bound** of two elements `a` and `b` in a poset `P` is an element `x`
such that both `x ≤ a` and `x ≤ b` hold. Similarly, a **lower bound** of a
family `a : I → P` of elements in `P` is an element `x` such that `x ≤ a i`
holds for every `i : I`.
