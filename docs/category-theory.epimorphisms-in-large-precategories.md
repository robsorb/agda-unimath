## Idea

A morphism `f : x → y` is a epimorphism if whenever we have two morphisms
`g h : y → w` such that `g ∘ f = h ∘ f`, then in fact `g = h`. The way to state
this in Homotopy Type Theory is to say that precomposition by `f` is an
embedding.
